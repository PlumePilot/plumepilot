# Supporto PlumePilot

PlumePilot è un progetto indipendente e non è affiliato, approvato o distribuito dall'Università Telematica Pegaso o da Multiversity.

## Segnalare un problema

Per bug riproducibili e richieste di funzionalità usa le [GitHub Issues](https://github.com/PlumePilot/plumepilot/issues) scegliendo il modello più adatto.

Prima di aprire una segnalazione:

1. aggiorna PlumePilot all'ultima versione disponibile;
2. verifica se esiste già una issue simile;
3. indica browser, versione di PlumePilot, pagina interessata e passaggi per riprodurre il problema;
4. oscura ogni dato personale negli screenshot.

Non pubblicare mai token di sessione, password, matricola, dati completi degli esami o contenuti didattici non necessari alla diagnosi.

## Segnalazioni private

Per problemi che contengono dati personali, informazioni di autenticazione o dettagli di sicurezza scrivi a [plumepilot@gmail.com](mailto:plumepilot@gmail.com). Per le vulnerabilità consulta anche [SECURITY.md](SECURITY.md).

## Limiti del supporto

Il progetto non può fornire assistenza sull'account, sulla carriera universitaria, sugli esami o sui servizi ufficiali Pegaso. Per tali richieste occorre rivolgersi ai canali ufficiali della piattaforma.
