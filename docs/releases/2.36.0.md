# PlumePilot 2.36.0 — release context

Updated 26 November 2026. Candidate branch `integration/plumepilot-english`. The user plans release during the week of 30 November–6 December 2026. Final store submission is pending.

## Included changes

- Shared Italian/English preference in the main and floating menus, defaulting to Italian. Localizes PlumePilot controls, messages, export tools, and Pausa?.
- HTML/PDF quizzes and PDF/EPUB handouts translate PlumePilot labels, including the generic “lezioni” section. Course questions, answers, and study material keep their original text. New offline HTML quizzes retain their export language when reopened and saved with notes.
- The quiz sidebar toggle stays accessible while scrolling at desktop and mobile widths.
- Gaming uses locally bundled Chakra Petch for interface text and controls, keeping Pixelify Sans for the PlumePilot title. Fonts and licenses are included. English tabs fit Small, Medium, and Large.
- Chrome uses distinct MAIN and ISOLATED language entry points. `page-language.js` is generated from `language.js` and `language-ui.js` using `node scripts/build-page-language.mjs`. The language-worlds test checks parity and guards against reusing the same script path across worlds.
- Firefox removes a leftover floating menu when reinjecting the extension after a reload. Menu hosts record the owning extension ID.
- Sound playback falls back to a supported platform tab if Chrome’s audio document cannot be created, contacted, or start playback. Failed exam alerts emit a console diagnostic.
- Repo testing includes the offscreen permission. Chrome/Edge store builds already included it before this change. Firefox packaging removes it.
- The update banner and the manual What’s new panel use the same release definition and selected language. What’s new is available in the main menu through Preferences → About. The floating menu has no release-notes entry.

## Sound investigation

A friend reported missing an exam sound in Chrome store version 2.35.3. Comparing that tag confirmed the same audio-document failure path existed there. Simulated document-creation failure aborts playback on 2.35.3 and reaches the tab fallback with the new fix. The exact cause on the friend’s computer remains unconfirmed.

Sound notifications must be enabled in PlumePilot and volume must be above zero. Exam sounds are triggered when a previously pending exam changes status. Initial baseline creation does not establish a transition. A real alert is independent of keyboard focus in the toolbar popup.

## Temporary N shortcut

The candidate currently contains `exam-alert-test.js`, registered in the isolated content-script group. On a supported platform page, press N to test playback with saved settings and a visible TEST message. The hook ignores editors, modifier combinations, key repeats, and rapid retriggers. It uses the normal background playback function through the sound-preview message.

This verifies playback, rather than exam-status detection. Keyboard focus must be on the platform page. An open toolbar popup receives the keystroke itself. The shortcut does not create a synthetic exam record.

Remove the file and its manifest entry after the user finishes testing, before final packaging. The user has not yet reported the result of the N test.
