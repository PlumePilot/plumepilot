# PlumePilot 2.34.0 — Multiversity expansion and reliability release

Version 2.34.0 expands PlumePilot beyond Pegaso to Mercatorum and San Raffaele/UTSR, improves adaptive EPUB output and strengthens long-running course operations.

## Changes

- Supports Pegaso, Mercatorum and San Raffaele/UTSR with isolated course and commission state for each platform.
- Makes the floating menu available from supported home and exam pages; course-only actions remain visible but disabled outside a course.
- Bounds and accelerates recovery for missing course handouts.
- Prevents hidden tabs from starting recovery reload loops.
- Preserves operation-scoped notification dismissal across reloads.
- Improves EPUB handling of formulas, tables and slide-like source pages.
- Enlarges Gaming launcher reward frames and clarifies the first-incomplete-activity achievement.
- Uses platform-neutral commission explanations throughout the runtime UI.
