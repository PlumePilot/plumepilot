# PlumePilot 2.33.1 — Reviewability release

Version 2.33.1 is a packaging-only follow-up to 2.33.0. It contains no feature or permission changes.

## Changes

- Replaced the minified pdf-lib 1.17.1, @pdf-lib/fontkit 1.1.1 and JSZip 3.10.1 files with the readable distribution files from the same official npm packages.
- Extracted the generated offline quiz logic into `offline-quiz-runtime.js`, where it remains readable and is embedded unchanged in standalone quiz downloads.
- Updated the AMO source instructions, third-party checksums and release validator.
- Removed the obsolete minified copies from runtime and source packages.

## Store submission

- Upload `plumepilot-v2.33.1-firefox.zip` as the extension package.
- Upload `plumepilot-v2.33.1-source.zip` as the source-code package requested by AMO.
- Use the matching value from `SHA256SUMS.txt` when recording or comparing package checksums.
- Chrome and Edge receive the same 2.33.1 codebase so all stores remain aligned.

## Regression checklist

- [ ] Open the popup and confirm the 2.33 feature set is unchanged.
- [ ] Generate and open a quiz PDF.
- [ ] Generate and open an offline interactive quiz; verify answers, themes, notes and annotated download.
- [ ] Generate course PDF and EPUB materials.
- [ ] Confirm the **Novità** notice appears once when updating from an older version.
