# PlumePilot 2.33.2 — Firefox AMO review-safety release

Version 2.33.2 is a packaging and static-review follow-up to 2.33.1. It contains no feature or permission changes, and no supported-host, privacy or data-handling changes.

## Changes

- The Firefox build replaces its unsupported Chromium offscreen-audio branch with the existing tab-based fallback.
- Exact, deterministic Firefox-only transformations remove legacy eval-like and variable-import fallbacks from JSZip, fontkit and PDF.js.
- PDF.js continues to use its interpreter because PlumePilot already requests `isEvalSupported: false`; normal module-worker and WebAssembly paths remain intact.
- Dynamic values were removed from first-party Shadow DOM `innerHTML` templates and are now applied through DOM nodes and attributes.
- Release validation scans every JavaScript, module and HTML file in the generated Firefox ZIP for the constructs reported by AMO.
