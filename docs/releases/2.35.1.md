# PlumePilot 2.35.1 — Ordered autoplay and improved EPUB exports

Autoplay follows video order within and across chapters, including completed videos for revision. The optional “Skip completed video lessons” setting is off by default; enabling it skips videos at 100% while preserving forward course order.

The separate “Find first incomplete activity” command uses the master call as its first filter: it checks chapters marked below 100% in course order, then verifies objectives, videos and tests in their details. Completed objectives are excluded; missing percentages remain unknown instead of becoming 0%. If no candidate contains pending activities, it verifies the other chapters before declaring everything complete. The command shows pending tests without answering them, independently of autoplay test settings. With completed-video skipping enabled, autoplay similarly locates its forward target through API details and opens the target chapter directly; requested test boundaries are preserved.

This update also improves recovery with closed chapter/section accordions and repeated chapter numbers. Material and test exports keep the title of the course where collection started, even if another course is opened before collection finishes. The floating menu has a compact chapter-limit selector. The dark Gaming menu mascot carries its candle while the minigame keeps the flying sprite.

EPUB exports now use the approved regional converter automatically: safely separated prose reflows around preserved formula/diagram images, mathematical Unicode characters use a locally embedded font when needed, and repeated encoded images share one asset. Complex layouts retain conservative visual fallback. A clickable section/chapter index appears after the cover, with a return link from each chapter. This reuses course metadata and adds no second rendering pass. Savings depend on the document; EPUB file-size reductions are not RAM measurements.

Firefox users upgrading from 2.34.0 also receive the 2.35 features: the 90-second Pausa? minigame, richer offline HTML quiz notes, question review statuses and filters.

Prepared packages use manifest and browser-specific Novità version 2.35.1. All 28 Node suites and package validation pass; all four ZIPs reproduce byte for byte from the supplied source archive. web-ext 10.7.0 reports 0 errors, 0 notices and 2 innerHTML warnings on the generated Firefox package. Live-browser upgrade and reader checks remain before submission. No store submission has been performed.

The export panels also offer download and usage instructions for the optional separate PdfToEpub desktop converter.
