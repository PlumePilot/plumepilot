# PlumePilot 2.35.3 — Correzione salvataggio appunti HTML

Questo aggiornamento corregge un solo problema: il testo `\n` che compariva in alto nei quiz HTML e si accumulava a ogni salvataggio con appunti.

I nuovi quiz generati includono il codice corretto. I file HTML scaricati in precedenza non vengono modificati automaticamente. Nessun’altra modifica funzionale o nuovo permesso.

## Note per gli store / release GitHub

Corretto un problema che aggiungeva il testo `\n` in alto nei quiz HTML a ogni salvataggio degli appunti. La correzione si applica ai nuovi quiz generati con questa versione.

## Reviewer notes (EN)

This patch only fixes a literal backslash-n appearing and accumulating in exported offline HTML quizzes when saving notes. Generate a new HTML quiz, add notes, click “Scarica HTML con appunti”, reopen the saved file and repeat. No stray text should appear at the top; notes should be preserved. Previously downloaded HTML files are not updated by the extension.

The user confirmed the fix works in their browser before release preparation. No store submission or release tag has been created during preparation.
