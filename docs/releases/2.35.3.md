# PlumePilot 2.35.3 — Appunti nei quiz HTML

- Elenchi automatici: in un paragrafo vuoto, `- ` avvia un elenco puntato e `1. ` un elenco numerato. Doppio Invio per uscire.
- Seleziona il testo e premi Ctrl + \ (⌘ + \ su Mac) per rimuovere la formattazione, compresi i colori di evidenziazione. Il pulsante Tx usa la stessa azione. Esc conserva il suo comportamento.
- Corretto il testo `\n` che compariva in alto nei quiz e si accumulava a ogni salvataggio con appunti.

Le modifiche si applicano ai nuovi quiz HTML generati. I file già scaricati non vengono aggiornati automaticamente. Nessun nuovo permesso.

## Reviewer notes (EN)

This update improves the exported offline HTML notes editor. In an empty paragraph, type hyphen then Space for a bulleted list, or 1. then Space for a numbered list. Use Enter twice to exit. Select formatted/highlighted text and press Ctrl+backslash (Command+backslash on Mac), or click Tx, to remove formatting. Escape retains its existing behavior. Save with “Scarica HTML con appunti”, reopen and repeat: no literal backslash-n should appear at the top and notes should persist. Existing downloaded quizzes are not updated by the extension.

No store submission or release tag has been created during preparation.

All 29 Node test files pass. The Chromium regression check (`node tests/browser/offline-notes.cjs`, with Playwright installed) verifies automatic lists, double-Enter exit, ordinary text, Ctrl+backslash and Tx partial highlight/bold removal, and saved-note reopening.
