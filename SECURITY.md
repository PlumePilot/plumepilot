# Sicurezza

## Versioni supportate

Durante la fase pre-pubblicazione viene supportata soltanto l'ultima release candidata. Dopo la pubblicazione, gli aggiornamenti di sicurezza saranno applicati alla versione più recente disponibile negli store.

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Invia una descrizione a [plumepilot@gmail.com](mailto:plumepilot@gmail.com) includendo, se possibile:

- versione di PlumePilot e browser;
- impatto osservato;
- passaggi minimi per riprodurre il problema;
- eventuale prova tecnica priva di credenziali e dati personali.

Non inviare password o token validi. La ricezione verrà confermata appena possibile; tempi di analisi e correzione dipendono dalla gravità e dalla riproducibilità del problema.
